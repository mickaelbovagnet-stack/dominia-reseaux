# dominia-reseaux
  Visuels des publications Dominia sur LinkedIn, Facebook et Instagram. Média IA romand, dominia.ch

## Contenu

- `gabarits/generer.py` produit les visuels à partir d'un fichier JSON (gabarits actualite, couverture, etape, fin, cas, agenda), aux couleurs et en police Archivo du système de design DominIA.
- `publications/AAAA-MM-JJ/` reçoit les visuels publiés, un dossier par jour. Buffer lit les images par leur lien direct `raw.githubusercontent.com`.
- `apercus/` montre un exemple de chaque gabarit.

Tous les fichiers de ce dépôt sont destinés à être publiés. Aucun brouillon de texte ni aucune donnée confidentielle n'y est déposé.
